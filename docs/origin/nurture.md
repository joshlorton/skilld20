# SKILLd20 Origin -- Nurture

Nurture is the second half of Origin (see `nature.md` for Ancestry). It runs: **Culture** ->
**Early Childhood** (Family/Social Standing) -> **Late Childhood** -> **Adulthood** (a repeatable
Later Life loop; renamed from "Real Life" -- even children are living a real life, and "Adulthood"
follows the Childhood-stage naming pattern). Only Culture and Early Childhood are designed so far.

Skill ranks throughout Nurture are purchased on the standard skill rank point-buy curve: **1, 1, 2,
2, 3, 3, 4, 4, 4, ...** (cost per successive rank). Note that ranks 1 and 2 both cost 1 point each --
every Early Childhood entry below stays within rank 2 of any single skill, so its point totals can be
read directly off the "+N" values without extra conversion.

---

## Culture

- **Language(s):** Primary language at rank 5. Additional languages determined by lifepath choices.
  Literacy determined by lifepath; assume yes unless a specific lifepath choice states otherwise
  (see Back Woods and Street below, which both grant "no").
- **Government:** Not yet detailed -- per-culture content, not a mechanical structure.
- **Population:** Urban / rural -- not yet detailed.
- **Geography:** Not yet detailed.
- **Climate:** Not yet detailed.
- **Tech Level (TL):** Medieval is the standard baseline for testing. (See the broader TL/CL research
  in prior design work -- unresolved which of several candidate systems this ultimately maps to.)

## Early Childhood

A **10-point budget** applies to skill ranks. Each social-standing choice lists mandatory skills;
their point cost is subtracted from the base 10, and whatever remains is free for player choice.

### Social Standing

**Nobility**
- Culture (culture) +1
- Diplomacy +1
- History (culture) +1
- Language +1
- Second language +1
- Pick 1: Scholastic (government, heraldry, or law) +1

**Wealthy**
- Hobby +1
- Language +1
- Local (any 1) +1
- Profession (any 1) +1
- Scholastic (any 1) +1

**Commoner -- Farm**
- Pick 1: Handle Animal or Expertise (farming) +2
- Craft (any 1) +1
- Swim +1

**Commoner -- Trades**
- Appraisal +1
- Craft (any 1) +2
- Expertise (any 1) +1

**Impoverished -- Back Woods (rural)**
- Athletics +1
- Endurance +1
- Language -2 (literacy: no) -- *the point deficit is paid back into the 10-point budget*
- Survival +2
- Swim +1

**Impoverished -- Exiled**
- Blend +1
- Bluff +1
- Second language +1
- Pick 1: Streetwise or Survival +1

**Impoverished -- Orphan**
- Blend +1
- Scrounge +1
- Pick 1: Streetwise or Survival +1

**Impoverished -- Street**
- Carouse +1
- Language -1 (literacy: no) -- *paid back into the 10-point budget*
- Scrounge +1
- Streetwise +2

**Closed Community -- Militaristic**
- Pick 1: Acrobatics or Athletics +1
- Pick 1: Tactics (any 1) or Scholastic (military) +1
- Tight weapon group (any 1) +1
- Unarmed combat (any 1) +1

**Closed Community -- Monastic**
- Scholastic (religion) +2
- Meditation +1
- Pick 1: Craft (any 1), Lore (any 1), Expertise (any 1), or Scholastic (any 1) +1

### Design notes

- Negative language modifiers (Back Woods, Street) refund points into the 10-point budget rather than
  being a pure flavor penalty. Chosen deliberately over strict realism for balance -- these
  backgrounds needed more mandatory skills overall (young children in poorer/less structured
  circumstances still have real choices made for them, just fewer of them), and the refund keeps
  their net spend in line with the other Impoverished sub-paths (Back Woods and Street both net 3
  points spent after the refund, matching Orphan's 3 and close to Exiled's 4).
- Point totals are now roughly graded by social standing: Nobility spends the most (6 of 10, least
  free choice), Wealthy spends 5, Commoner/Closed Community/Exiled spend 4, and rural Impoverished
  backgrounds net 3 (most free choice). Reads as a deliberate gradient -- higher status means more of
  your training is decided for you; lower status means more freedom, less guidance.
- **Appraisal** does not appear in either skill glossary below, despite Trades relying on it directly.
  Open gap, not yet resolved.

## Draft Skill Glossaries

These are working lists from prior notes, not yet fully reconciled with the skills used above (most
line up; exceptions noted).

### Knowledge-type skills (all Int-based)

| Skill | Description |
|---|---|
| Culture | Traditions & actions |
| Expertise | You're good at this specific thing |
| Game/Sports | Rules, etc. (covers both mental and physical rule-based activities -- originally split into two skills, merged since "rules are rules" regardless of domain) |
| History | Historical facts |
| Language | Speak |
| Literacy | Read & write (should probably be a feat, not a skill -- open question) |
| Local | Geographical facts |
| Lore | Legendary facts |
| Scholastic | Academic facts |
| Science | Science |
| Strategy | Large scale |
| Tactics | Small scale |

### Skills requiring a subtype

| Skill | Ability | Description |
|---|---|---|
| Art | Int | Create a piece of visual art |
| Boat Handling | Dex | Pilot a type of boat |
| Craft | Int | Build an object |
| Dance | Dex | Dance monkey, dance! |
| Disable Device | Int | Break something (sabotage) |
| Engineering | Int | Design something |
| Gunnery | Int | Operate large weaponry -- at medieval TL, this means siege engines (ballista, catapult, trebuchet), not gunpowder weapons |
| Handle Animal | Wis | Teach tricks (training/command, distinct from Ride) |
| Hobby | Int | Something you find fun to do |
| Medical | Int | Advanced healing |
| Musical Instrument | Int | Play a type of instrument |
| Navigation | Int | Get around |
| Perform | Cha | Put on a show (oratory, sing) |
| Profession | Wis | A job |
| Repair | Int | Fix something |
| Ride | Dex | Mount up & go -- confirmed distinct from Handle Animal; different ability scores map to genuinely different actions (in-the-moment steering vs. training/command over time) |
| Teamster | Int | Drive an animal-powered vehicle |
| Use | Int | Use/operate something -- the vaguest entry here; needs a scope note (broad catch-all like Use Magic Device, or something narrower) before it's usable at the table |
