## GURPS 4e -- Colleges of Magic

Note: GURPS colleges do not map directly to the existing tradition categories (Arcane School, Bloodline, etc.). These would require a new ACCESS_GROUPS category such as "Arcane College (GURPS)" if GURPS-lineage characters appear in the system. Alternatively, they can be mapped to existing Arcane School entries thematically:
- Fire College → Arcane School: elemental: fire
- Earth College → Arcane School: elemental: earth
- Water College → Arcane School: elemental: water
- Gate College → (no current equivalent; new entry needed)
- Necromantic College → (maps to divine undeath domain thematically, but is an arcane school)

Recommend: treat GURPS colleges as a separate ACCESS_GROUPS entry when the time comes, rather than folding into existing categories.

## Notes for Implementation

1. All [verify] entries should be confirmed against the physical book before adding to ACCESS_GROUPS.
2. Specialty priest titles from Faiths and Avatars are often descriptive rather than a formal class name -- some deities don't name their priests distinctly. The titles above are either directly sourced or thematically derived.
3. Priest spheres from 2e map roughly to PF1e/PF2e domains, but the mapping is not 1:1. The SKILLd20 Divine Domain category should use the system's own domain list rather than importing these directly.
4. The Draconic bloodline sub-types (Black, Blue, etc.) are already granular in PF1e; SKILLd20 may prefer a single "Draconic" bloodline entry with dragon color as a character-level detail.
5. PF1e subdomain entries number 100+; add selectively based on what appears in Foundation access requirements.
