# SKILLd20 Feats -- PF1e Unchained Rogue Talents

Draft SKILLd20 XP costs for Pathfinder Unchained's (2015) new Rogue Talent additions, priced as
standalone Feats via the formula in `conversion-methodology.md`. Unlike combat maneuvers or Core
Spellcasting traditions, these have **no confirmed SKILLd20 landing spot** -- priced as standalone
Feats per explicit choice, not assumed to feed a future Focus-list system.

Scope: only Pathfinder Unchained's own new talent additions to the Rogue (Unchained) talent list --
not the much larger pre-existing Rogue Talent catalog an Unchained Rogue can also pick from. 43
entries total (27 base + 16 advanced), matching Archives of Nethys's own source index exactly.

**Formula specifics for this set:** a prerequisite talent counts as +1, same as a prerequisite feat.
"Rogue level Nth" / "advanced talents" gates scale +1 per point of the level -- "advanced talents" is
shorthand for "rogue level 10th," so it contributes +10. Rogue's Edge (an automatic class feature
gained at level 5, not itself a talent pick, and not literally phrased as a numbered level) stays a
flat +1 when required -- it names a class feature, not a class level. Baseline "can pick rogue
talents at all" isn't counted as a dimension.

## How to apply

Base-tier talents are mostly flat and low (2 or 3), since almost none of Unchained's own new base
talents carry ability-score, BAB, or skill-rank prerequisites. **Advanced Talents are not cheap**
(12-13 each), driven almost entirely by the rogue-level-10 gate rather than talent-chain depth. If
these get reworked into a Focus-list system later (matching how Combat Maneuvers or Core
Spellcasting traditions work), these numbers would need re-deriving under that different shape, not
reused directly.
