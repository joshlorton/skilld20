# Faerûnian Holy Days & Ceremonies -- Master Calendar

Aggregated across every deity processed from *Faiths & Avatars* (TSR 9516). Appended to as each
deity's file is completed -- see individual `docs/deities/<deity>.md` files for full ceremony
descriptions; this file tracks just the name, timing, and deity for quick cross-referencing.

## Dated Holy Days, in Calendar of Harptos Order

Only entries tied to an actual fixed point on the Calendar of Harptos (a numbered day-of-month, or
one of the five/six special festival days) are placed here. Entries whose source timing is "daily,"
"nightly," "monthly," "as needed," "personal rite," lunar-phase-based, or tied to a real-world
event with no stated calendar date (e.g. Selûne's Hallowing, Kossuth's per-temple birthdate
festival) are excluded from this section -- they stay in the main table above only. A few entries
are marked *(approx.)* where the source gives relative timing (e.g. "12 days after Greengrass") or
an equinox/solstice description rather than literally naming the festival day; these are placed at
their nearest calendar equivalent, not asserted as textually exact.

## How to apply

This file is a running index only -- do not treat it as authoritative over each deity's own `.md`
file, which has the full ceremony description. The dated section above is now the chronologically
sorted view; the main table remains the complete, deity-sorted index of every ceremony regardless of
whether it has a fixed calendar date.
